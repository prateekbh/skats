# Launcher art

Generated by `tools/prepare_launch_art.py` from the source images in `tools/launch_src/`, except
`turbokat_hero.png` and `city_attack.png`, which the game renders (`tools/render_launch_art.py`).
Don't edit these files by hand; re-run the script instead:

```bash
pip install pillow numpy scipy potracer
```

```bash
python3 tools/prepare_launch_art.py
```

| File | What | Where it appears |
|---|---|---|
| `logo.svg` | SWAT KATS logo, traced to vectors (also copied to `assets/ui/logo.svg`) | Launcher centre panel, in-game menu, launch |
| `swat_kats.png` | T-Bone and Razor cut-out | Launcher hero panel |
| `dark_kat.png`, `turmoil.png` | Villain cut-outs | Launcher villain panels |
| `callie.png` | Callie Briggs still | Launcher panel |
| `face_*.png` | Portraits | Villain portrait in the launcher's briefings |
| `turbokat_hero.png` | Our TurboKat banked in flight, rendered by the game | Launcher centre panel |
| `city_attack.png` | A missile-damaged tower burning, rendered by the game | Launcher "KA-BLAM!" panel |

CI copies `web/launch/*.png` and `*.svg` next to `index.html` (see `.github/workflows/web.yml`).
