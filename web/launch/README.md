# Launch-screen art

Generated by `tools/prepare_launch_art.py` from the source images in `tools/launch_src/`.
Don't edit these files by hand; re-run the script instead:

```bash
pip install pillow numpy scipy potracer
```

```bash
python3 tools/prepare_launch_art.py
```

| File | What | Where it appears |
|---|---|---|
| `logo.svg` | SWAT KATS logo, traced to vectors (also copied to `assets/ui/logo.svg`) | Loading screen, title menu, intro |
| `swat_kats.png` | T-Bone and Razor cut-out | Loading screen centrepiece |
| `dark_kat.png`, `turmoil.png` | Villain cut-outs | Looming over the skyline |
| `callie.png` | Callie Briggs still | Source for her portrait |
| `face_*.png` | Radio portraits | Loading-screen comm panel |

CI copies `web/launch/*.png` and `*.svg` next to `index.html` (see `.github/workflows/web.yml`).
