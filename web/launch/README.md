# Launch-screen character art

The browser loading screen (`web/shell.html`) arranges these images into a key-art poster.
Any file that is missing simply drops out of the layout.

| File | Character | Placement |
|---|---|---|
| `razor.png` | Razor | Large hero, left |
| `tbone.png` | T-Bone | Large hero, right |
| `callie.png` | Callie Briggs | Supporting, left-centre, behind the heroes |
| `feral.png` | Commander Feral | Supporting, right-centre, behind the heroes |
| `dark_kat.png` | Dark Kat | Looming faintly in the sky above the logo |

Best results: **transparent-background PNG cut-outs**, full or three-quarter body, at least
1000 px tall. Razor should face right (toward the centre) and T-Bone left.
Rectangular stills also work: their bottom edge fades into the city automatically.
